WoR Mod Manager 1.1.0

- Map mods: a mod for a map now installs where the game loads it (Assets/Levels/<Map>/levelmm.pak, plus its z_ paks in Assets) and switches on and off like any other mod. Zips with a wrapper folder, a "War of Rights/Assets/..." layout or only a Levels folder all land in the right place, and a map-only zip no longer says "No mod files found".
- WoR Map Editor builds show up as one "Map editor: <Map>" card per map, in your game and on your servers, so you can switch one map's edits off without touching the others.
- Mods that replace a game file now work: the original file is kept aside and put back when you switch the mod off or remove it (those cards say "Replaces game files"). If a game update has changed that file since, you're warned instead of getting an old copy back.
- New Servers tab: save your game servers' FTP logins (G-Portal works; passwords are encrypted for your Windows account), see what's installed on each, and install mods from My Library or by dropping a zip on the tab. Switch them on and off, update or remove them, and adopt mods that were put there by hand.
- Stop the server before you switch mods off, remove or update them on it: a running server keeps its mod files open, so it refuses, and the manager tells you so. Start it again afterwards to load the changes.
- Some hosts (G-Portal included) delete mod files when the server restarts. The Servers tab shows what's missing, and "Reinstall all missing" puts it all back in one go.
